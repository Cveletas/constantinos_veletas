# Constantinos Veletas Portfolio

A plain HTML/CSS/vanilla JS aerospace engineering portfolio designed for GitHub Pages.

## Files
- `index.html` — single-page portfolio
- `styles.css` — responsive styling and design tokens
- `assets/` — project imagery, patches, ACX logo, and résumé PDF

## Preview locally
Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deployment
Push the folder to a GitHub repository and enable GitHub Pages from the `main` branch, root folder.
